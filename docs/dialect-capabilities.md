# Dialect capabilities

`SqlDialectCapabilityCatalog` is the validation-time source of truth. Interface membership does not imply support for every future object or option.

| Capability | PostgreSQL | MySQL |
|---|---:|---:|
| Table objects | Yes | Yes |
| Database objects | Yes | Yes |
| Schema-qualified table names | Yes | Yes (database-qualified semantics) |
| Identity column rendering | `GENERATED BY DEFAULT AS IDENTITY` | No |
| Auto-increment rendering | No | `AUTO_INCREMENT` |
| `NO ACTION`, `RESTRICT`, `CASCADE`, `SET NULL` | Yes | Yes |
| `SET DEFAULT` referential action | Yes | No |

Capabilities are checked before document rendering. The model is intentionally extensible, but version 1.1 does not declare or implement schemas, indexes, views, sequences, routines, or other roadmap objects.
